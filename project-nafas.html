Nafas - Perfume Showcase

A calm, multi-page website that displays a perfume catalog with a clean white identity.

Role

Design & Development

Stack

HTML, CSS, JavaScript

Year

2026

OverView

Nafas is a display-only perfume catalog: customers browse products and learn about the brand, with no online checkout. It has several pages and interactive details built with JavaScript

What I Built

A home page, an about page and a visit page, a product showcase, a calm white visual identity and responsive layouts.

The Challenge

I started without a brand, so I had to choose the colors, spacing and typography myself. The hardest part was keeping a calm, clean white identity consistent across every page without it looking generic.

What I Learned

Small details like spacing and hover states make a site feel real. I also learned to publish a multi-page site on GitHub Pages, where file and folder names must match exactly.
